## How the data is collected

- **The vendor's own pages.** The company comes from the terms of use, the privacy policy or the site footer; the
  core version from the changelog or the release notes; plans and prices from the pricing page, with monthly
  billing. Each record lists these pages in `sources`. Pages behind a bot check are read from the Wayback Machine.
- **Automatic checks** (`tools/collect.py`): whether the website answers, where it is hosted, the domain's
  registration date (RDAP), its first capture in the Wayback Machine, and stars, last push, licence and latest
  release for GitHub projects. `tools/upstream.py` fetches the current Chrome and Firefox versions for the core lag.
- **Tests by hand** (status ✅): a fresh profile of the product is opened on
  [CreepJS](https://abrahamjuliot.github.io/creepjs/), [Pixelscan](https://pixelscan.net/),
  [BrowserScan](https://www.browserscan.net/), [Iphey](https://iphey.com/),
  [Fingerprint.com](https://demo.fingerprint.com/playground) and
  [BrowserLeaks WebRTC](https://browserleaks.com/webrtc), and what they show is written down with the date and the
  version ([`tests`](./data/README.md#tests)).

No account is created and no software is downloaded by the automatic checks.

Corrections and new products are welcome as pull requests: edit or add a file in [`data/products/`](./data/products/)
in the format of the others, with a link to the page that shows each fact. Facts without a source, marketing text and
referral links are not accepted. Run `python3 tools/test_data.py --no-site` before you open the pull request.
